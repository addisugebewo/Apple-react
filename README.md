# 🍎 React Apple Project

A React-based Apple website practice project built with **React** and **Vite**.

This project is part of my web development learning journey. I built it to practice React components, JSX, CSS, images, and organizing a modern frontend project.

## 🚀 Technologies Used

- React
- Vite
- JavaScript
- JSX
- CSS
- ESLint
- Git & GitHub

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/react-apple.git
```

### 2. Go into the project folder

```bash
cd react-apple
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL shown in your terminal, usually:

```text
http://localhost:5173/
```
